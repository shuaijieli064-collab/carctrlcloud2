- 诊断：PC 侧 `GET /cmd?c=0` 与 `GET /cmd?c=s` 均返回 OK，串口回显 `0` / `SPEED=100%` / `FAN OFF` / `STOP_ALL` → HTTP→CmdProcess 链路完全正常，问题只在电机输出这一环。
- 根因判断：**硬件 PWM 首次上板无输出**。Web 版(795,376 B) 上电默认 `g_speed=50` → `MotorDrive` 走 `IoTPwmStart(0,50,10000)`；而实测能跑的自由移动版(784,880 B) 是 `IoTGpioSetOutputVal` 常高、无 PWM。PWM 版/Web 版此前只做离线验证，**从未实机验证过电机输出**。
- SDK 核查（结论：静态配置无误）：`IoTPwmInit` = `hi_pwm_set_clock(160M)` + `hi_pwm_init`；`IoTPwmStart` 换算 `hiFreq=160000000/freq`、`hiDuty=duty*hiFreq/100`；`hi_pwm_port` 枚举 PWM0=0 / PWM1=1；`CLKEN1_PWM0=0` / `CLKEN1_PWM1=1`；`CONFIG_PWM_SUPPORT=y` 已开且驱动已链接。SDK 内无其他 PWM 示例可对照 → 属驱动/硬件层未输出，不是指令或协议问题。
- 已把板端**运行时**速度设为 100%（绕过 PWM、GPIO 常高），注意**重上电会回到 50%**，需再点一次「全速」。临时只用方向按钮，别拖摇杆（摇杆按幅度发 1~9 档会把板端切回 PWM，车立刻停）。
- 待用户验证「全速 + 前进」是否动：动 = 确诊 PWM；不动 = 查底板电池开关/电量、电机接线。后续三条路：① 不重烧、全速玩 ② 出 `exp8_webui_gpio_burn.bin`（禁用 PWM 分支、摇杆可用、调速暂失）③ 继续查硬件 PWM 保住 10 档调速（需多次试烧）。
