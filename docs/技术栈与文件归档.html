技术栈描述与文件归档

项目：carctrlcloud2（全场景智能寻检车 APP） · 更新：2026-11-14 · 图例：主文件 核心业务 / 过程·测试文件 联调与验证工具 / 文档·配置

一、技术栈总览

层技术在本项目中的作用
APP 端语言/框架ArkTS + ArkUI 声明式 UI，Stage 模型，API 22 页面组件（Index/ControlPage）、状态驱动渲染（@State）、自定义 Joystick 组件
系统能力@kit.NetworkKit socket.TCPSocket（直连模式）、socket.TLSSocket（secureOptions+CA）、http（HTTPS 轮询与命令）
自研加密库SHA-256 / HMAC-SHA256 / Base64 / UTF-8 编解码（零第三方依赖） MQTT 密码鉴权（两种模板）、HTTPS V11-HMAC-SHA256 请求签名（HKDF 派生）
自研协议栈MQTT 3.1.1 最小客户端/服务端、RFC6455 WebSocket 最小实现（Python） broker 与设备端不引入 paho/websocket 库，教学可读 + 抓包可控；ArkTS 侧 MqttClient 自研报文编解码
PC 端语言Python 3.12，仅标准库（socket/ssl/threading/asyncio/ssl 上下文） 虚拟小车运动学、TCP/WS/MQTT 三类服务、设备接入脚本、集成测试
云平台华为云 IoTDA 标准版（cn-north-4）+ IAM 子用户 设备接入（MQTTS 8883）、设备影子、命令下发、物模型校验；应用侧开放 API（HTTPS 443）
可视化ArkUI Canvas（APP 俯视图）+ 浏览器 Canvas（webview.html） 轨迹/状态实时渲染，数据源为 100ms state 帧或 1s 影子轮询
关键设计约定：① 零第三方依赖——鸿蒙侧与 Python 侧全部自研；② 运动学单一真源 car_model.py，所有端的状态渲染都来自它；③ 双拓扑并存——本地模拟（教学/抓包）与真平台（已端到端实测）可一键切换。

二、APP 端文件归档（entry/src/main/ets/）

文件类别作用
pages/Index.ets主文件 首页：模式选择（云端/TCP-DEBUG/华为云）+ 连接入口，携带参数跳转 ControlPage
pages/ControlPage.ets主文件 操控主页面：摇杆（死区0.08/低通0.55/节流200ms）、状态卡、俯视图 Canvas、回执日志区；三模式命令分发
net/TcpClient.ets主文件 TCP 直连客户端（DEBUG）：连接 8888、\n 分帧收发、ping 保活
net/MqttClient.ets主文件 自研 MQTT 客户端：CONNECT/CONNACK、SUBACK、PUBLISH、心跳；connectTls() 支持真平台 8883
net/IotBridge.ets主文件 IoTDA 风格 topic 模板、命令 payload 编码（move/stop/ping）、属性解析；导出加密原语供签名复用
net/HuaweiCloudClient.ets主文件 华为云直连（模块⑤）：V11-HMAC-SHA256 签名、影子 1s 轮询、同步命令下发、凭证校验
model/CommandProtocol.ets主文件 指令协议单一真源：帧定义、编解码、seq 自增、非法帧容错（返回 null）
common/CarConfig.ets主文件 全局配置：寻址（模拟器/真机）、端口、CLOUD_*（endpoint/region/deviceId/projectId/轮询节律）
view/Joystick.ets主文件 自定义摇杆组件：触点跟随、位移归一化回调
entryability/EntryAbility.ets主文件 Stage 模型入口 Ability，加载 Index
entrybackupability/EntryBackupAbility.ets过程 模板自带的备份能力，未参与业务

三、模拟器/车端文件归档（simulator/）

文件类别作用
car_model.py主文件 虚拟小车运动学单一真源：速度/转向/电量/位置积分，转向死区 0.05
car_server.py主文件 TCP 直连服务（模块③）：:8888 控制帧 + :8889 俯视图 WS 广播（自研 RFC6455）
mqtt_broker.py主文件 本地 MQTT broker（模块④）：:1883 CONNECT 鉴权（双注册表）、通配订阅路由 + :8899 俯视图 WS
mqtt_protocol.py主文件 IoT 协议层：鉴权模板（local/real 两套）、topic 构造、命令解析（容错）、注册表常量
mqtt_client.py主文件 自研 MQTT 客户端：明文/TLS（ssl.wrap_socket）、自动 PINGREQ 心跳、中文排障提示
car_mqtt_device.py主文件 车端设备脚本：local 模式（本地 broker）/ real 模式（真平台 TLS，官方鉴权）；配置自动加载；命令执行+属性上报
app_mqtt_client.py主文件 APP 替身集成测试（9 用例）：鉴权/属性/命令/容错/互踢，端到端验收工具
run_iot.py过程 一键启动器：清理端口 → broker(1883/8899) → 车端 → 打开浏览器俯视图
test_client.py过程 TCP 直连模式的早期手动测试客户端（模块③联调遗留）
webview.html主文件 浏览器俯视图：Canvas 轨迹渲染，WebSocket 只收 state 帧（只看不控）
iotda_config.json文档·配置 车端 real 模式凭证（host/port/tls/device_id/secret）——敏感文件，勿提交仓库
iotda_car_model.json文档·配置 产品 carCtrl 物模型（可在 IoTDA 控制台导入）：属性 5 项 + 命令 move/stop/ping
logs/car_real.log 等过程 运行日志输出
