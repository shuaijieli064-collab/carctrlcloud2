## 三、教师侧：导出（实测用 --vhd 模式，8 分钟）

### 为什么用 --vhd 而不是 tar

| | tar 模式（旧方案） | **--vhd 模式（实测采用）** |
|---|---|---|
| 原理 | 逐文件打包 35G | 整盘直拷 |
| 实测耗时 | 1.5 小时未完成且失败 | **8 分钟完成** |
| 产物 | .tar（约35G） | **.vhdx（34.84G）** |

### 导出前两个必须动作（踩过的坑）

1. **先彻底关停 WSL**（否则报"文件被占用"SHARING_VIOLATION）：
   ```powershell
   wsl --shutdown
   ```
2. **导出期间不要执行任何 wsl 命令**（包括 `wsl -l -v` 以外的一切会唤醒发行版的操作）。
3. 另注意：WSL 会自动升级自己——若导出中途 WSL 触发自升级会把导出进程杀掉（本次第一次 tar 失败即此原因）。升级刚完成后的窗口期导出最稳。

### 导出命令（PowerShell）

```powershell
wsl --export oh3861 E:\oh3861-student.vhdx --vhd
```

（E: 换成移动硬盘实际盘符）

### 导出后的验证（金标准，本机已完成 ✅）

```powershell
wsl --import oh3861-test D:\OpenHarmony\WSL-test E:\oh3861-student.vhdx --vhd
wsl -d oh3861-test -- bash -c "cd ~/oh3861 && bash build.sh --product-name wifiiot_hispark_pegasus --ccache --no-prebuilt-sdk"
# 看到 build success 即镜像完好，然后清理临时系统：
wsl --unregister oh3861-test
```

实测结果：build success（26 秒）。验证后临时系统已注销，D 盘空间已释放。

## 四、分发方式

| 方式 | 操作 | 适合 |
|---|---|---|
| 移动硬盘 | 学生轮流拷，或老师挨个机器导 | 班级规模小、有实体机房课 |

## 五、学生侧：从零搭建（操作卡内容）

### 第 0 步：装机自检（2 分钟）

| 检查项 | 要求 | 怎么查 |
|---|---|---|
| 系统 | Win10（19044+）或 Win11 | Win+R 输 `winver` |
| 虚拟化 | 已开启 | 任务管理器 → 性能 → CPU → "虚拟化: 已启用"（没启用需进 BIOS 开 VT-x/AMD-V） |
| 内存 | 建议 16G（8G 可编译但偏紧） | 任务管理器 |
| 空闲磁盘 | ≥40G（用"U盘直读法"）或 ≥75G（先把 vhdx 拷进电脑） | 此电脑 |
| 管理员权限 | 第 1 步需要一次 | — |

### 第 1 步：开启 WSL 功能（需重启）

开始菜单搜 **PowerShell** → 右键 **以管理员身份运行**：

```powershell
wsl --install --no-distribution
```

跑完**重启电脑**。（老版本 Win10 若提示不认识该参数，改跑两条 `dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart` 和 `dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart` 再重启；重启后如报"内核未安装"，跑一次 `wsl --update`。）

### 第 2 步：导入镜像

把移动硬盘插上（假设盘符 E:），PowerShell（普通权限）：

```powershell
wsl --import oh3861 D:\wsl\oh3861 E:\oh3861-student.vhdx --vhd
```

- 第一个参数 `oh3861`：系统名（固定用这个，和教学文档一致）；
- 第二个参数：虚拟磁盘落盘位置（**建议 D 盘**，别放 C 盘；目录不存在会自动建）；
- 第三个参数：vhdx 来源路径——**可以直接写移动硬盘路径**，不必先把 35G 拷进电脑（"U盘直读法"，省学生机 35G 峰值空间，代价是导入稍慢）；
- **结尾的 `--vhd` 参数不能漏**（镜像就是 vhdx 格式，漏了会按 tar 解析报错）。

耗时约 15~25 分钟。完成后 `wsl -l -v` 应显示 `oh3861    Stopped    2`。**导入成功后 vhdx 文件对学生就没用了**（拷贝来的可以删，移动硬盘传给下一位）。

### 第 3 步：验证（也是每次开课的标准动作）

```powershell
wsl -d oh3861
```

进入 Ubuntu 后依次：

```bash
cd ~/oh3861
ls                          # 应看到 build.sh、kernel、vendor、applications 等
./build.sh --product-name wifiiot_hispark_pegasus --ccache --no-prebuilt-sdk
ls out/hispark_pegasus/wifiiot_hispark_pegasus/*.bin   # 看到 Hi3861_wifiiot_app_burn.bin 即成功
```

编译约 30 秒~2 分钟，结尾出现 `build success` 就说明环境完好。（首次编译因无缓存比教师的 19 秒慢，正常。）

### 第 4 步：烧录工具（写好程序后烧车用）

1. 安装 CH341 串口驱动（CH341SER.ZIP，老师发放，CH340/CH341 通用）；
2. 拷贝 `HiBurn.exe`（可放 D 盘）；
3. 固件在 Ubuntu 的 `~/oh3861/out/...`，拷到 Windows：`cp out/.../Hi3861_wifiiot_app_burn.bin /mnt/d/`。

### 学生端故障速查

| 现象 | 处理 |
|---|---|
| `wsl --install` 报错或重启后仍不可用 | 用 dism 两条命令（见第 1 步括号）+ `wsl --update` |
| 导入报"不支持该文件" | 确认命令结尾有 `--vhd`；检查 vhdx 是否拷完整（比对文件大小 ≈34.84G） |
| 导入报"另一安装正在运行" | 等几分钟重试（WSL 自身在升级） |
| 导入后 `wsl -d oh3861` 进不去 | `wsl --terminate oh3861` 后重进；还不行删除 `D:\wsl\oh3861` 重新 import |
| 编译报权限/只读错误 | 确认没把工程放在 /mnt/ 路径下编译；重新 `cd ~/oh3861` |
| 磁盘满 | 虚拟磁盘在 D:\wsl\oh3861\ext4.vhdx，只增不减；别往 /root 塞大文件 |
